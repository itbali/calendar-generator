# Генератор Календарей

Современное React-приложение для создания и печати настраиваемых календарей.

## Описание

Приложение позволяет создавать календари в различных режимах (год, месяц, неделя, день) с гибкими настройками:
- Множество цветовых тем
- Управление праздниками разных стран
- Пользовательские праздники
- Настройка ориентации и заголовков
- Оптимизация для печати

## Компоненты

### Основные компоненты

- **App** - корневой компонент приложения
- **CalendarProvider** - провайдер контекста для управления состоянием
- **Controls** - панель управления настройками
- **CalendarPreview** - отображение сгенерированного календаря

### Компоненты Calendar

- **MonthCalendar** - отображение месячного календаря с ячейками для каждого дня
- **YearCalendar** - годовой планировщик с 12 месяцами
- **WeekCalendar** - недельный планировщик с 7 днями
- **DayCalendar** - дневной планировщик с временными слотами
- **TaskLines** - переиспользуемый компонент строк для задач

### Компоненты Controls

- **ViewModeSelector** - выбор режима отображения (год/месяц/неделя/день)
- **ThemeSelector** - выбор цветовой темы
- **AdditionalSettings** - дополнительные настройки (ориентация, чекбоксы и т.д.)
- **HolidayManagement** - управление праздниками и их отображением

## Контекст

**CalendarContext** управляет всем состоянием приложения:

- Настройки отображения (режим, год, месяц, ориентация)
- Настройки календаря (количество строк, чекбоксы, заголовки)
- Управление праздниками (выбор стран, пользовательские праздники)
- Выбранная тема
- Toast уведомления
- Автоматическое сохранение в localStorage

## Утилиты

### constants.js
- Цветовые темы (5 вариантов)
- Названия месяцев и дней недели
- Данные о странах и их праздниках

### dateUtils.js
- Функции для работы с датами
- Парсинг дат праздников
- Вычисление дней в месяце
- Поиск понедельника недели

### storageUtils.js
- Сохранение и загрузка настроек из localStorage
- Разделение настроек календаря и праздников

## Хуки

### useTheme
Применяет выбранную тему к CSS переменным документа с учетом настройки контрастных выходных.

## Стили

Стили разделены на модули:

- **App.css** - основные стили приложения и layout
- **Calendar.css** - стили для всех видов календаря
- **Controls.css** - стили панели управления
- **Toast.css** - стили уведомлений

## Особенности

### Управление состоянием
Используется Context API для централизованного управления состоянием. Все настройки автоматически сохраняются в localStorage.

### Темы
Приложение поддерживает 5 цветовых тем:
- Синяя (по умолчанию)
- Зеленая
- Фиолетовая
- Теплая
- Монохромная

Темы применяются через CSS переменные для легкой кастомизации.

### Праздники
- Поддержка праздников из 9 стран
- Возможность добавления пользовательских праздников
- Индивидуальное включение/выключение каждого праздника
- Сохранение выбора в localStorage

### Печать
Специальные стили для печати с:
- Адаптивным масштабированием под формат A4
- Поддержкой книжной и альбомной ориентации
- Скрытием элементов управления
- Оптимизацией размеров шрифтов

## Миграция с Vanilla JS

Оригинальное приложение на чистом JavaScript сохранено в файлах:
- `old-vanilla-index.html` - оригинальная HTML версия
- `old-index.html` - резервная копия

Все функциональные возможности сохранены и улучшены в React версии.
